## 🔧 НАСТРОЙКА FIREBASE

### Если создаёте свой сайт:

1. **Создайте проект в Firebase:**
   ```
   https://console.firebase.google.com
   ```

2. **Получите конфиг:**
   ```javascript
   const firebaseConfig = {
     apiKey: "YOUR_KEY",
     authDomain: "...",
     projectId: "...",
     ...
   };
   ```

3. **Обновите в index.html:**
   ```
   Найти строку "const firebaseConfig = {"
   Заменить на вашу конфигурацию
   ```

4. **Настройте Rules в Firestore:**
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /documents/{document=**} {
         allow read: if true;
         allow write: if true;
       }
     }
   }
   ```

5. **Пушьте:**
   ```
   git push
   Netlify развернёт автоматически!
   ```

## 🆘 ЧАСТЫЕ ВОПРОСЫ

### ❓ Как изменить пароль редактирования?

```javascript
В index.html найти:
if (userPassword !== "teacher") return;

Изменить на:
if (userPassword !== "ваш_пароль") return;
```

### ❓ Как добавить свои документы в начальный набор?

```
1. Откройте index.html
2. Найти: const BASE64_DOCUMENTS = {
3. Добавить вашу ссылку на файл
4. Или загрузить через режим редактирования
```

### ❓ Можно ли работать без Firebase?

```
Да! Приложение работает и без Firebase.
Но синхронизация между пользователями не будет.

Файлы будут сохраняться:
- Локально в браузере (IndexedDB)
- При экспорте в один HTML файл

Firebase добавляет облачную синхронизацию.
```

### ❓ Это опасно для конфиденциальности?

```
Нет! Потому что:
- Файлы хранятся в вашем Firebase (ваши данные)
- Никто не может видеть содержимое
- Только вы контролируете доступ
- HTTPS всегда защищает передачу
```

### ❓ Сколько это стоит?

```
Бесплатный уровень Firebase:
- 1 ГБ хранилища
- 100k чтений/месяц
- 50k записей/месяц

Достаточно для:
- 100+ пользователей
- Месяцы использования
- Нулевой стоимости! ✅
```
