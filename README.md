# Блокнот молодого учителя

Интерактивный методический блокнот для учителей русского языка и литературы.

## Что внутри

- 3D-блокнот с перелистыванием страниц
- Методические разделы и материалы
- Файлы к урокам (документы, презентации, PDF)
- Личные заметки учителя
- Облачная синхронизация: правки и файлы видны на любом компьютере

## Для кого

Для педагогов, методистов и молодых учителей — как удобная «копилка» материалов и подсказок в одном месте.

## Авторский режим

Позволяет редактировать тексты разделов, загружать файлы и создавать папки. Изменения сохраняются в облаке.  
Личные заметки остаются только на вашем устройстве.
